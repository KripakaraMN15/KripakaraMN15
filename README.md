## 👨‍💻 About

I'm a software engineer from Mangaluru, India, with industry experience at **Samsung R&D** and **CodeIO**. I like the full path from model to product: training and compressing models, then wrapping them in apps people can actually use.

- 🧠 **98.48% accuracy** on voice-command detection at Samsung, using a 3-model ensemble (ALBERT + Naive Bayes + rule-based) that beat standalone BERT by ~2.5 pts, compressed to **46MB** with **56ms** inference
- 🏗️ Built an exam management platform for **5,500+ students**, cutting admin effort by **~60%**
- 🤖 Build AI products on the side: voice-to-invoice, chat-to-chart, and a 5-agent travel planner
- 🏆 Finalist: **OpenFire Hackathon** (2026) and **Magicpin Vera AI Challenge** (2026)
- 💬 Ask me about LangGraph, RAG, multi-agent orchestration, or why model compression is secretly the fun part
